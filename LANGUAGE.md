# Language variants

This repository contains two complete sketches with identical logic:

| File | Language |
|------|----------|
| `esp32_ble_gamepad_id.ino` | Indonesian (Bahasa Indonesia) — original UI messages |
| `esp32_ble_gamepad_en.ino` | English — translated OLED messages and comments |

Shared files (use with either sketch):
- `hid_pad.h`
- `hid_pad.cpp`

Only user-facing strings and comments differ. All functions, variables, pins, and behavior are the same.
